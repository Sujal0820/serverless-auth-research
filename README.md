# Serverless Risk-Aware Authentication

A research project investigating a risk-aware, invocation-bound dynamic
token authentication framework for secure serverless computing.

## Research Components

- Risk-Based Authentication
- Invocation-Bound Dynamic Tokens
- Replay Attack Protection
- Federated Learning
- Serverless Computing
- Security and Performance Evaluation

## Target Architecture

The system will be implemented using AWS serverless services and
evaluated against selected authentication baselines.

## Project Structure

- `infrastructure/` - AWS infrastructure and Terraform
- `backend/` - Authentication and security services
- `experiments/` - Security and performance experiments
- `datasets/` - Research datasets
- `results/` - Experimental results and figures
- `frontend/` - Authentication and monitoring interface
- `docs/` - Architecture, experiments and design decisions
